# Main Gaussian-copula experiment

This directory contains the completed primary Gaussian-copula Monte Carlo experiment.

## Design

- 2022 BRFSS empirical baseline covariate pool: 324,636 complete cases from 445,132 source records.
- 4,000 observations per Monte Carlo replicate.
- 100 replications per scenario.
- Scenarios: standard overlap and weak overlap.
- True ATE: 2.0.
- Synthetic generator: transparent empirical Gaussian copula.
- Estimators: crude difference, cross-fitted g-computation, IPW, and cross-fitted AIPW.
- Primary estimator: cross-fitted AIPW.
- Base seed: 20260811.

## Primary result

The Gaussian releases show strong conventional statistical fidelity but do not perfectly preserve the causal analysis. For AIPW, synthetic-reference distortion RMSE is 0.230 under standard overlap and 0.312 under weak overlap. Real-vs-synthetic discriminator AUC is approximately 0.516 and 0.517, respectively. The result therefore supports task-specific causal-utility evaluation rather than using conventional fidelity as a proxy for causal preservation.

Reference AIPW 95% coverage is 0.96 under standard overlap and 0.93 under weak overlap; Gaussian-synthetic AIPW coverage is 0.86 in both scenarios. These are diagnostic Monte Carlo results, not a complete synthetic-data combining-rule procedure.

## Files

- `main_results_table.csv` — compact reviewer-facing causal table.
- `causal_summary.csv` — full Monte Carlo causal summary, including truth-relative error and synthetic-reference distortion.
- `fidelity_summary.csv` — aggregate statistical, predictive, mechanism, and oracle diagnostics.
- `data_audit.csv` — BRFSS screening and complete-case retention audit.
- `aipw_release_level.csv` — release-level AIPW estimates, synthetic-reference distortion, conventional fidelity, and overlap diagnostics for all 200 scenario-replicates.
- `overlap_summary.csv` — compact overlap diagnostics.
- `timing_summary.csv` — compact runtime summary.
- `run_config.json` — executed configuration.

The full replicate-level `estimates.csv`, `fidelity.csv`, and `overlap.csv` are generated by the pipeline but are not required in version control; they can be reproduced from the committed code, configuration, and source workbook. No BRFSS respondent-level rows and no row-level synthetic datasets are included.

## Diagnostic interpretation

Truth-relative error and synthetic-reference distortion answer different questions. A synthetic release can move a biased estimator closer to the known truth while still changing the result that would have been obtained from the matching reference sample. Both metrics are therefore retained.

Mechanism diagnostics are secondary to the prespecified ATE-preservation metrics. In particular, the primary DGP has a constant individual treatment effect, so fitted treatment-contrast correlations can be unstable because any fitted heterogeneity reflects estimation noise/model approximation rather than true effect modification.

## Interpretation boundary

These results evaluate causal utility under a controlled semi-synthetic DGP. They do not establish clinical validity, anonymity, disclosure protection, or differential privacy. The Gaussian copula is used as a transparent synthesis baseline rather than a state-of-the-art generator. CTGAN remains optional and is not part of the reported primary result.
